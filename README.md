# AEO / GEO 크롤러 가시성 계측기

웹페이지 하나를 넣으면 **AI 에이전트가 거기서 무엇을 가져갈 수 있는지**를 측정합니다.

👉 **https://kohoy13.github.io/aeo-checker/**

AI 에이전트(ChatGPT · Claude · Perplexity 등)는 **자바스크립트를 실행하지 않습니다.**
그래서 사람이 보는 화면과 봇이 가져가는 내용이 다릅니다.
이 계측기는 **서버가 내려준 원본 HTML**을 기준으로 네 단계를 봅니다.

| 단계 | 질문 | 보는 것 |
|---|---|---|
| ① 접근 | AI 봇이 들어올 수 있나 | robots.txt — 봇 18종을 쓰임(검색 / 인용 / 실시간 / 학습)별로 경로마다 판정 |
| ② 발견 | 이 쪽이 있다는 걸 아나 | sitemap.xml 에 이 주소가 있는지 |
| ③ 수신 | 서버가 본문을 내려주나 | 봇이 읽는 글자 vs 스크립트에 숨은 글자 · 렌더 방식 판별 |
| ④ 식별 | 무슨 쪽인지 기계가 아나 | title · description · canonical · OG 표준 여부 · JSON-LD |

## 글자를 세 겹으로 셉니다

```
① 봇이 읽는 글자    태그 안 텍스트 (script · style · noscript 제거 후)
② 숨은 글자         하이드레이션 JSON 안 문자열 (__NUXT__ · __NEXT_DATA__ 등)
③ 사람이 보는 글자  ① + ②
```

**①이 ③에 비해 작으면 화면은 멀쩡한데 봇에게는 빈 쪽입니다.**

## 쓰는 법

검사할 쪽의 **원본 HTML**을 붙여넣습니다. 브라우저가 그린 화면이 아니라
**서버가 내려준 것**이어야 봇이 보는 것과 같습니다.

```bash
curl -sL -A "Mozilla/5.0" "주소" | pbcopy
```

또는 브라우저 주소창에 `view-source:주소` 를 넣고 전체 복사.
robots.txt · sitemap.xml 도 넣으면 더 정확해집니다 (선택).

## 휴대폰에 설치

- **아이폰** 사파리로 열기 → 공유 → 홈 화면에 추가
- **안드로이드** 크롬으로 열기 → 점 세 개 → 앱 설치

설치하면 전체화면으로 뜨고, **인터넷 없이도 돕니다.**
바깥에서 받아오는 것이 하나도 없는 한 파일짜리입니다.

## 개인정보

넣은 내용은 **어디로도 전송되지 않습니다.** 전부 브라우저 안에서만 계산합니다.
서버도 분석 도구도 없습니다.

## 한계

- 로그인이 필요한 쪽은 그 쪽의 HTML 을 직접 떠서 넣어야 합니다
- 봇마다 실제 동작이 다를 수 있습니다. **robots 를 지키고 JS 를 실행하지 않는 봇**을 전제로 봅니다(가장 보수적)
- **실제로 AI 답변에 인용되는지**는 알 수 없습니다. '인용될 수 있는 상태인가'까지만 봅니다
- 이미지 안의 글자는 세지 않습니다
